# 王阳明心学对话 Skill

用现代白话演绎王阳明心学对话的 Cursor / Grok Bot skill。

## 用法

把 `SKILL.md` 放进你的 skills / workflows 目录（或按所用产品的 skill 安装方式导入）。

用 `/` 或 `@` 调用；聊心学、知行合一、致良知、日常抉择时也可加载。

## 内容

- `SKILL.md` — 可调用的 skill 正文
- `notes/` — 蒸馏底稿（资料清单、结构化笔记、人格边界、蒸馏摘要等）

## 风格

现代汉语为主，少文言；可结合当代日常决策举例。史实与引文不编造；不确定处会标明。

## 许可

公开分享；引用请注明出处。
