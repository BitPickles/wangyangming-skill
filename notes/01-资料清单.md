## 一、概述

### 1.1 范围

本清单覆盖四类资料：

1. **原典著作**：语录、书信、问难、奏疏公移、全集版本  
2. **生平与历史背景**：年谱、行状、墓志、纪传、年表与考订  
3. **后人解读与学术研究**：明清注疏、学术史、当代哲学史专著与英文经典研究  
4. **现代阐释与落地读物**：职场/决策/情绪等通俗引申（一律标注「通俗/引申」）

### 1.2 使用原则

| 原则 | 说明 |
|------|------|
| 原典优先 | 蒸馏 skill 应以《传习录》《大学问》及可靠全集文本为根，不以畅销通俗书替代 |
| 学术与通俗分开 | 通俗书可作「现代落地案例」素材，但须与义理原文对照，避免把引申当原意 |
| 版本意识 | 《年谱》有嘉靖天真本、赣州本与通行隆庆《全书》本等差异；引生平须注明所据版本 |

## 二、原典

### 2.1 核心文本（精读首选）

#### 《传习录》（上、中、下）

| 字段 | 内容 |
|------|------|
| 作者/编者 | 王守仁讲学语录与书信；徐爱、陆澄、薛侃、钱德洪等门人陆续辑录编定 |
| 为何重要 | 阳明心学最集中的语录与书信合集；「知行合一」「致良知」「心即理」等核心命题多见于此。通行本收入《王文成公全书》；上卷语录，中卷书信（含著名长函），下卷语录及《朱子晚年定论》 |
| 通行本线索 | 明隆庆六年（1572）谢廷杰刻《王文成公全书》所收三卷本，为今通行「全书本」 |
| 公开获取 | 维基文库：https://zh.wikisource.org/zh-hans/%E5%82%B3%E7%BF%92%E9%8C%84 ；ctext：https://ctext.org/wiki.pl?if=gb&remap=gb&res=873181 ；Gutenberg：https://www.gutenberg.org/ebooks/25517 |

**中卷关键书信/短文（篇名据通行结构；具体条次以所选校本为准）：**

- 《答顾东桥书》（含「拔本塞源」一大段论学，常被单称「拔本塞源论」）  
- 《答周道通书》  
- 《答陆原静书》（及「又」）  
- 《答欧阳崇一》  
- 《答罗整庵少宰书》  
- 《答聂文蔚》（及「二」）  
- 《训蒙大意示教读刘伯颂等》《教约》

#### 《大学问》

| 字段 | 内容 |
|------|------|
| 作者 | 王守仁（门人记录/编入全集） |
| 为何重要 | 晚年以「大人者以天地万物为一体」阐释《大学》「明明德」「亲民」「止至善」，是理解「万物一体」「良知」「格物」的纲领性问答 |
| 公开获取 | ctext：https://ctext.org/wiki.pl?chapter=759384&if=gb ；亦见《阳明先生集要》理学编及各《王阳明全集》 |

#### 《朱子晚年定论》

| 字段 | 内容 |
|------|------|
| 作者 | 王守仁编选朱熹书札以论证「朱子晚年与己同」 |
| 为何重要 | 反映阳明自我定位及与朱子学对话策略；争议大，读时宜对照学术批评，不宜单独当作朱熹思想定论 |
| 公开获取 | 通常附《传习录》下 / 《王文成公全书》；ctext 相关章节可检索 |

**现代阐释使用建议（供后续蒸馏）：**

1. 先立原典义项（如「知行合一」在《传习录》中的多种表述），再对照通俗书如何改写。  
2. 落地场景（决策、情绪、责任）可以通俗书启发选题，但例证优先用来自年谱/奏疏的「事上」材料，而非虚构职场寓言。  
3. 对「此心光明」「破心中贼」等流行金句，须核是否原典原句或后出概括。
